🍽️ Myu — Веб-приложение для онлайн-ресторана
Myu — это одностраничное веб-приложение (SPA) для онлайн-ресторана. Оно предоставляет пользователям удобный интерфейс для просмотра меню, выбора блюд по категориям и оформления заказов.

🔧 Технологии
React с TypeScript — для построения компонентов и обеспечения типизации.

Redux Toolkit — для управления состоянием приложения.

Vite — для быстрой сборки и разработки.

CSS Modules — для модульного и изолированного стайлинга компонентов.

gh-pages — для деплоя на GitHub Pages.

📁 Структура проекта
src/ — исходный код приложения.

public/ — статические файлы.

db.json — имитация базы данных для разработки.

docs/ — папка для сборки проекта, используемая при деплое на GitHub Pages.

🚀 Деплой
Приложение автоматически деплоится на GitHub Pages с помощью следующих npm-скриптов:

"scripts": {
  "predeploy": "npm run build",
  "deploy": "gh-pages -d docs"
 }

🏗️ Для работы:

npm run serve:api
Сервер API (бэкенд-эмуляция) 
http://localhost:3001	
Отдает/принимает данные из db.json

 npm run dev
 Интерфейс (фронтенд)	
 http://localhost:5173	
 Показывает твой React-приложение
